A colossal blue whale breaching out of a stormy sea at sunset, silhouetted
against a huge low sun — with one tiny sailboat below it for scale.

`main.py` (Python 3 standard library only, no network, deterministic) draws
the image and writes a 1024x1024 PNG to `$MAKEFUN_OUTPUT_DIR/entry.png`
(or `/output/entry.png`).

Run it twice and the two PNGs are byte-identical.

## Run it

```sh
python3 main.py
```
